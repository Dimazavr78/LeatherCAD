LeatherCAD — CAD-приложение для создания кожевенных выкроек прямо в браузере. Оно объединяет точную геометрию, ассоциативные размеры, разметку шва, отверстия, слои и бесконечный SVG-холст в одном специализированном рабочем пространстве.

> [!IMPORTANT]
> LeatherCAD находится на ранней стадии разработки. Версия `0.0.12` подходит для экспериментов, но сохранение проектов, экспорт файлов и полноценный производственный процесс пока не реализованы.

## Основные возможности

- Бесконечный SVG-холст с панорамированием, масштабированием к курсору, адаптивной сеткой, линейками и объектными привязками.
- Прямоугольник, линия, полилиния, окружность, дуга, скругление, размеры и измерения.
- Выбор, перемещение, изменение размера, ручки радиуса и точное редактирование в Properties.
- Ассоциативные ссылки на геометрию: размеры и зависимые объекты следуют за исходной фигурой.
- Круглые, овальные и скруглённые прямоугольные отверстия, связанные с основной деталью.
- Абсолютное, относительное и краевое позиционирование отверстий.
- Параметрический шов вдоль внешних контуров и вокруг отверстий.
- Рекурсивные зависимости, безопасное удаление и Undo/Redo.
- Слои, вложенные уровни проекта, буфер обмена и перемещение с клавиатуры.
- Интерфейс на русском и английском языках.
- Семантические кожевенные детали, ссылающиеся на существующий замкнутый контур без копирования геометрии.
- Встроенные и пользовательские материалы, переопределение толщины, предпросмотр материала, параметры реза и проверка деталей.

## Быстрый запуск

Требования:

- Node.js 22 или новее
- npm 10 или новее

```bash
git clone https://github.com/Dimazavr78/LeatherCAD.git
cd LeatherCAD
npm install
npm run dev
```

Откройте адрес, который выведет Vite — обычно это `http://localhost:5173`.

### Полезные команды

```bash
npm run dev                         # Запустить frontend
npm run dev:back                    # Запустить экспериментальный backend
npm run build                       # Собрать frontend и backend
npm run test --workspace=front      # Запустить тесты редактора и геометрии
npm run lint --workspace=front      # Проверить frontend линтером
npm run preview --workspace=front   # Просмотреть production-сборку
```

## Основной рабочий процесс

1. Выберите инструмент рисования и создайте базовую геометрию.
2. Инструментом **Выбор** переместите или измените объект; точные значения доступны в **Свойствах**.
3. Добавьте ассоциативные размеры или используйте временные размеры выделения.
4. Выберите **Отверстие** и щёлкните внутри прямоугольника, окружности или замкнутой полилинии.
5. Настройте форму и положение отверстия в **Свойствах**.
6. Выберите **Шов** и щёлкните по контуру либо используйте кнопку **Добавить шов вокруг отверстия**.
7. Организуйте проект с помощью слоёв и вложенных уровней.

### Навигация и горячие клавиши

| Действие | Управление |
|---|---|
| Панорамирование | Средняя кнопка мыши или `Shift` + перетаскивание левой кнопкой |
| Масштабирование | Колесо мыши |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Y` |
| Копировать / вставить | `Ctrl+C` / `Ctrl+V` |
| Дублировать | `Ctrl+D` |

| Точное перемещение | Стрелки |
| Крупное перемещение | `Shift` + стрелки |
| Отменить операцию | `Esc` |

## Ассоциативная модель

LeatherCAD не хранит вычисляемые координаты, если их можно получить из исходной геометрии:

```text
CAD-геометрия
├── геометрические anchors
├── ассоциативные размеры
├── отверстия
│   ├── вычисляемое положение
│   └── шов
└── шов по внешнему контуру
```

`PartObject` служит семантической производственной оболочкой над одним замкнутым контуром. Площадь, внешний периметр, общая длина реза, отверстия, швы и размеры вычисляются из актуальных ссылок проекта. Материалы и режим отображения входят в состояние документа и поддерживают Undo/Redo.

`GeometryReference` определяет объект и одну из его логических опорных точек. Единый источник опорных точек используется привязками и размерами. Отверстие хранит ссылку на родительский контур и правило позиционирования, а не только отдельную координату центра. Точки шва и значения размеров вычисляются из актуальной геометрии.

## Текущие ограничения

- Нет сохранения/открытия и формата проектов `.lcad`.
- Нет экспорта в DXF и PDF.
- Нет булевых операций, Trim, Extend, 3D и системы сборок.
- Преобразование произвольной полилинии в Custom Hole пока не реализовано.
- Ограничение отверстий внутри окружностей и полилиний пока использует bounding box.
- Auto Dimensions пока редактируются через диалог, а не встроенный SVG-input.
