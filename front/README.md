# LeatherCAD frontend

React, TypeScript, Vite, and SVG frontend for LeatherCAD.

Project documentation: [English](../README.md) · [Русский](../README.ru.md)

```bash
npm run dev --workspace=front
npm run test --workspace=front
npm run lint --workspace=front
npm run build --workspace=front
```

Translations live in `src/locales/`; editor geometry and domain behavior live in `src/editor/`.
