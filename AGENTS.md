# Repository documentation rules

- Keep `README.md` and `README.ru.md` synchronized whenever user-facing behavior, setup commands, architecture, limitations, roadmap items, or the project version changes.
- Update both README version badges when the package version changes.
- Keep the feature lists factual; do not document planned behavior as implemented.
- If a new UI language is added, create a matching localized root README and add it to the language navigation in every root README.
- Before committing documentation changes, verify that all documented npm commands exist in the relevant `package.json` files.
